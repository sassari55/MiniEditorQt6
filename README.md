Il programma è un software che crea file di testo. Permette il salvataggio, la stampa, 
la ricerca all'interno del testo.
Permette la modifica dei font ed è possibile colorare il testo, oltre ad evidenziarlo 
in grassetto, corsivo, sottolineato, a seconda delle esigenze.
In pratica è simile a molti editor di testo, ad esempio: gEdit, Kwrite, ecc.
Inoltre nella barra di stato sono visibili i conteggi delle parole e dei caratteri.
Il programma è sotto licenza open-source e come tale può essere modificato, installato su 
qualsiasi piattaforma.
Il programma è stato compilato con l'ide CLions, interfacciato con Qt6, creato codice sfruttando gli
standard del C++ 26 e utilizzato il compilatore gcc 15 su server AlmaLinux 9.8.
